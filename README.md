## 다른 사주 앱과 다른 점

같은 시각을 넣어도 계산 프로그램마다 결과가 갈리는 구간이 있습니다 —
한국의 서머타임 시행기(1948~51, 1955~60, 1987~88), 표준시 기준이 달랐던
시기(1954~61), 자시 경계(23~1시), 절기 경계.

대부분의 사주 서비스는 이를 알리지 않고 하나로 단정합니다.
